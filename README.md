# Portal dos Livros

Projeto da disciplina de Tecnologia para Frontend Avançado da UNIESP (2026.2).

A ideia é criar um site para pesquisar livros, visualizar os resultados e acessar os detalhes de cada obra, usando uma API pública.

## Tecnologias

- React
- TypeScript
- Vite
- API de livros (Google Books ou Open Library, conforme definição da equipe)

## Como executar

```bash
npm install
npm run dev
```
